# CoronLP ZMK

CoreX側で整えたキー配列と、共通のバグ修正をCoronLPへ移植した構成です。
右がCentral、センサーは既存のPMW3610、左右ともロータリーエンコーダーは使いません。
基板配線・400 CPI・125 Hz・LED設定はCoronLPの構成を維持しています。

## 操作

- WIN／MACの基本配列、NUM、FN、PAN_WIN／PAN_MAC、GESTURE、MOUSE、BLUETOOTHの9レイヤーです。
- NUMは上から1 2 3／4 5 6／7 8 9。FNはF1 F2 F3／F4 F5 F6／F7 F8 F9です。
- CoreXと親指配置が違うため、NUMの0とFNのF10は左の追加親指キー（位置46）、FNのF11・F12は右下2キー（位置49・50）へ割り当てています。
- 右内側親指（位置48）はFN、隣の親指（位置47）は短押しLANG2／長押しNUMです。
- 左親指（位置44）は短押しLANG1／長押しスクロール、位置45は押している間ジェスチャーです。
- 位置18は短押しで範囲スクリーンショット（WIN＝Win＋Shift＋S、MAC＝Command＋Shift＋4）、長押しでBluetoothレイヤーです。
- 位置19はズーム100％（WIN＝Ctrl＋0、MAC＝Command＋0）です。通常のキー操作で、エンコーダーは不要です。
- NUM／FN共通で右手の左側に `\`、`()`、`[]`、`{}`、`_`、`~`、グレイヴを配置しています。
  括弧ペアはUS配列基準で、入力後にカーソルを間へ戻します。
- ボール操作でMOUSEレイヤーへ入り、J／K／L＝左／中／右クリック、M／カンマ＝戻る／進むです。
  MOUSEは通常キー入力で解除されます。クリックと戻る／進むのキーは解除対象から除外しています。
- NUM／FN中はボール移動によるMOUSEレイヤーの割り込みを抑制しています。
- 慣性スクロールの上限は、既存のローカル編集に合わせて2秒です。
- BluetoothのY／U／I／O／引用符位置で接続先0〜4を選択します。接続先0はMAC、1〜4はWINを保存します。
  USB用の配列保存先とは分離し、再接続時に保存した配列を適用します。
- 文字入力用やJK／KLの同時押しコンボは、移植元の現在の構成と同じく定義していません。

## 更新

成功したGitHub Actionsのfirmware成果物から左右のUF2を取得してください。
ZMK Studioに旧配列を保存している場合は、今回の初期配列を使うためにキー配列をリセットします。
ペアリングを含む全設定消去は、この更新のためだけには不要です。
移植後の実機動作は未確認です。センサー方向、クリック、親指キー、接続先別のWIN／MAC復元を確認してください。
